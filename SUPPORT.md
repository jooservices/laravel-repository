# Support

Thank you for using `jooservices/laravel-repository`. Use these channels to get help.

## Documentation

- [README](README.md) — requirements, installation, quick start, package boundaries, and development commands
- [Documentation hub](docs/README.md) — architecture, user guides, examples, and development references
- [Changelog](CHANGELOG.md) — changes by release
- [Upgrade guide](UPGRADE-4.0.md) — changes and migration steps for the v4.0.0 line
- [Contributing](CONTRIBUTING.md) — project setup and contribution workflow

## Questions and bugs

For usage questions and bug reports, open a [GitHub issue](https://github.com/jooservices/laravel-repository/issues). Include your PHP and Laravel versions, a minimal reproduction, and the expected and actual behavior.

## Security

Do not report suspected vulnerabilities in public issues. Follow [SECURITY.md](SECURITY.md) for private reporting.

## Conduct

Community interactions follow the [Code of Conduct](CODE_OF_CONDUCT.md). Contact the maintainers at [admin@jooservices.com](mailto:admin@jooservices.com) to report a conduct concern.

## Commercial support

For commercial support, contact JOOservices at [admin@jooservices.com](mailto:admin@jooservices.com). Maintainer support is best-effort; no response SLA is guaranteed.
